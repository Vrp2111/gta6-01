# Lumen Bay

Sunset Run is an original procedural Three.js coastal driving game. Explore five golden-hour districts as Leo Vance in the orange Solstice GT, walk the waterfront, follow eight story-job briefs, and survive a named LBPD pursuit with traffic, pedestrians, and a helicopter. Afterglow has a playable delivery checkpoint; later jobs are story previews.

Run `node serve.ts`, then open http://127.0.0.1:8080. Use WASD to drive or walk, Space to brake, Shift to boost, E to exit or enter, F to enter nearby, M to switch radio, H to sound the horn, and Escape to pause. Select NEW GAME for Afterglow; `?play=job1` runs its automated checkpoint test.

Screenshots: `1-chase.jpg`, `2-onfoot.jpg`, `3-mission.jpg`, `4-start.jpg` in screenshots/. Build the dossier with `MAKEFUN_OUTPUT_DIR=/tmp/lumen-output node main.ts`.
