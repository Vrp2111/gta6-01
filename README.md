# LUMEN BAY

**A sunset coast, an open road, and a crew with one last run to make.** Explore five districts on foot or behind the wheel of the SOLSTICE GT in this original browser-based 3D driving game.

**Referral code:** `s75rqb78`

Run locally with `node serve.ts`, then open the printed local URL in a desktop browser. Drive with WASD, brake with Space, use E to leave or enter the car, Shift for nitro, M to change radio, and Esc to pause. Append `?shot=chase`, `?shot=onfoot`, `?shot=mission`, or `?shot=start` to view the deterministic capture setups.
